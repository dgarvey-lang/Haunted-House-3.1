# The Haunted House of Systems

An interactive Halloween-themed practice game for **Intermediate Algebra 3-1: Systems of Equations**.

Students walk through a haunted house, open any of 13 doors (numbered to match the paper worksheet), and solve the problem behind each one to win a puzzle piece. Collecting all 13 pieces completes a picture.

## Features

- Problems cover checking ordered pairs, solving by graphing (with an interactive grid), and using Desmos.
- Three levels of help: a hint, more help, and the full solution. Using more help or the full solution means the student must solve a similar, randomly generated problem on their own before earning that door's piece.
- Spooky music and sound effects (can be turned off).
- Progress is saved in the browser on that device.
- When finished, students get a **teacher code** tied to their name.

## Teacher view

Open the page with `#teacher` at the end of the URL (or click "Teacher: read student codes" at the bottom) to decode student codes, one at a time or a whole class pasted from a spreadsheet or Google Form.

## Running it

It is a single file with no build step. Open `index.html` in a browser, or enable GitHub Pages for this repository (Settings → Pages → deploy from the default branch) to get a link to share with students.
